# FilterBlock Implementation

## Overview
The FilterBlock performs noise filtering on pixel pairs generated by the DataGenerationBlock using a convolution kernel. **Each row is processed independently** - pixels from the next row are NOT used in filtering.

## Key Features

### 1. **Kernel Coefficients**
The filter uses a 9-element kernel (stored as `KERNEL` static array):
- K-4th: 0.00025177
- K-3rd: 0.008666992
- K-2nd: 0.078025818
- K-1st: 0.24130249
- K (center): 0.343757629
- K+1st: 0.24130249
- K+2nd: 0.078025818
- K+3rd: 0.008666992
- K+4th: 0.000125885

### 2. **Filtering Process**

For each pixel to be filtered, the algorithm:
1. Collects 4 pixels before it + the pixel itself + 4 pixels after it = 9 pixels total (all within same row)
2. Performs dot product with the kernel coefficients
3. Clamps result to 0-255 range
4. Returns filtered value

### 3. **Row Independence** ⭐

**CRITICAL**: Rows are processed independently. No data from the next row is used for filtering.

For a row with **m columns** (total pairs = m/2):
- Pair 1, 2, 3, 4 cannot be filtered (not enough past pairs in row)
- Pairs 5 through (m/2 - 4) **CAN be filtered**
- Last 4 pairs cannot be filtered (not enough future pairs in row)
- **At end of row: buffer is CLEARED**

**Example:** Row with 10 columns (5 pairs):
- Pair 1, 2, 3, 4 → No filtering possible
- **Pair 5 → ONLY filterable pair in this row**
- Columns 8-9 are the only pixels that get filtered
- End of row → buffer cleared

**Example:** Row with 18 columns (9 pairs):
- Pairs 1-4 → No filtering (accumulate in buffer)
- Pair 5 → **Start filtering** (output pair 5)
- Pairs 6-9 → **Continue filtering** (output each)
- End of row → buffer cleared, next row starts fresh

### 4. **Buffering Strategy**

The FilterBlock maintains a buffer of up to 5 pairs (10 pixels) to minimize memory usage **within each row**:

**Per Row:**
- Pairs 1-4: Accumulate in buffer (cycles 1-4, no output)
- Pair 5 onwards: If filterable, output filtered pair + rotate buffer
- **End of row: Clear buffer, reset pair counter to 0**

**Flow Example (18 columns = 9 pairs per row):**
```
Pair 1: buffer=[P1]         no output
Pair 2: buffer=[P1,P2]      no output
Pair 3: buffer=[P1,P2,P3]   no output
Pair 4: buffer=[P1,P2,P3,P4] no output
Pair 5: buffer=[P1-P5]      OUTPUT filtered pair 5
Pair 6: buffer=[P2-P6]      OUTPUT filtered pair 6
Pair 7: buffer=[P3-P7]      OUTPUT filtered pair 7
Pair 8: buffer=[P4-P8]      OUTPUT filtered pair 8
Pair 9: buffer=[P5-P9]      OUTPUT filtered pair 9
End:    buffer=[]           CLEARED for next row
```

### 5. **Memory Efficiency**
- Buffer size: Fixed at 5 pairs (10 pixels) × sizeof(pair) ≈ 80 bytes max
- Constant memory footprint across all rows
- Buffer cleared at end of each row

### 6. **API** (Key Methods)

```cpp
FilterBlock filter;

// Initialize with COLUMNS per row (REQUIRED)
// Determines which pairs within each row can be filtered
filter.initialize(numColumnsPerRow);

// Add pairs and get filtered output
std::pair<uint8_t, uint8_t> result = filter.addPairAndFilter(dataPair);

// MUST call at end of each row (clears buffer, resets pair counter)
filter.endOfRow();

// Check status
int cycle = filter.getCycleCount();
int pairInRow = filter.getPairIndexInRow();
size_t bufferSize = filter.getBufferSize();

// Reset for reuse
filter.reset();
```

### 7. **Edge Handling**
- Pairs 1-4 in each row: Accumulation phase (no output)
- Pairs 5 onwards: Active filtering **ONLY for rows with ≥9 pairs**
- End of row: Buffer cleared, pair index reset
- Total filterable pairs per row = max(0, pairsPerRow - 8)

## Integration with DataGenerationBlock

The main CynLr.cpp demonstrates the complete pipeline:
1. DataGenerationBlock generates pixel pairs per row
2. FilterBlock buffers and filters them (within each row)
3. **endOfRow()** called between rows
4. Filtered output ready for further processing

## Example Usage

```cpp
DataGenerationBlock dataGen;
dataGen.loadRandom(10, 18);  // 10 rows, 18 columns

FilterBlock filter;

// Initialize with columns per row
filter.initialize(dataGen.getNumColumns());

int rowCount = 0;
int pairCount = 0;
int pairsPerRow = (dataGen.getNumColumns() + 1) / 2;

while (!dataGen.isFinished()) {
    auto rawPair = dataGen.getNextPair();
    auto filteredPair = filter.addPairAndFilter(rawPair);

    pairCount++;

    // Check if end of row
    if (pairCount >= pairsPerRow) {
        filter.endOfRow();  // Clear buffer for next row
        rowCount++;
        pairCount = 0;
    }

    if (filteredPair.first != 0 || filteredPair.second != 0) {
        // Process filtered pair
        std::cout << "Row " << rowCount << ", Filtered: [" 
                  << (int)filteredPair.first << ", " 
                  << (int)filteredPair.second << "]\n";
    }
}
```

## Important Notes

1. **Must call initialize()** with number of columns before using the filter
2. **Must call endOfRow()** after processing each row's pairs
3. **Rows are independent** - next row data never reaches previous row's filtering
4. With 10 columns: Only pair 5 (columns 8-9) gets filtered per row ✓
5. With fewer than 9 pairs per row: No pairs can be filtered in that row
6. Buffer size is always ≤ 5 pairs regardless of image dimensions
